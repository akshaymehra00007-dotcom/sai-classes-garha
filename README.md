# SAI CLASSES GARHA

A static one-page website for SAI CLASSES GARHA in Garha, Jabalpur.

## Files

- `index.html` — page content and local business metadata
- `styles.css` — responsive layout, typography and motion
- `script.js` — menu, scroll reveals and small interactions
- `favicon.svg` — site mark
- `robots.txt` — crawler access rules

This site has no package install or build step. The site files are served from the repository root. Contact actions link to the published phone number and WhatsApp number; directions and the map link to Google Maps.
